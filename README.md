# Guppy's Towers of Hecc 4
GToH now running at a buttery smooth framerate.

## Contributing
Want to mod or help with development? Here is how to compile the game:
1. Download and install [Node.js](https://nodejs.org/en).
2. Clone this repository: `git clone https://github.com/guppyadrian/GToH-4.git` or alternatively download the repo as a zip file and unzip it.
3. Open a terminal in the project's root directory.
4. Install node modules with `npm install`.
5. Run the game with `npm run dev`. You should be able to play it by going to `https://localhost:5173`.
6. You can compile the game with `npm run build`. The compiled game will be in the `dist/` folder.
